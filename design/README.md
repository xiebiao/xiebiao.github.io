# 网站主色调

当前网站以暖白、炭灰和酒红三种颜色构成主要视觉基调。

| 颜色 | 色值 | 用途 |
| --- | --- | --- |
| 暖白 | `#faf8f5` | 全站页面背景 |
| 炭灰 | `#2c2c2c` | 标题、主要文字和图标 |
| 酒红 | `#7d2942` | 链接、Hover、Focus 等交互强调 |

后续扩展设计时，优先围绕这三个颜色建立新的页面和组件，以保持整体风格一致。

主色与辅助灰阶在 `static/style.css` 的 `:root` 中统一管理。正文、次要说明、日期与图注分别使用对应的语义变量，交互强调统一使用酒红。照片、头像和项目 Logo 保留各自的原始颜色。
